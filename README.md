# AX-Mentoring-8 AI 면접 기출 문제

AI 면접에서 나온 질문 예시입니다. 각 질문의 발표 시간은 5분입니다.

## 면접 질문

- **Q1.** AI 개발자로서 본인의 장점은 무엇인가요?
- **Q2.** 해당 시스템은 사용자에게 어떤 도움을 주나요?
- **Q3.** 시스템을 고도화한다면 어떤 기능을 추가하고 싶으신가요?
- **Q4.** 내부망에 적용하기 위해 추가로 개발해야 할 부분은 무엇인가요?
- **Q5.** 보험 청약 불완전판매 점검 문제를 해결할 때, 자동화 범위를 어디까지로 정할지 어떻게 판단하셨나요?
- **Q6.** 이 프로젝트가 해결하려는 핵심 비즈니스 문제는 무엇이며, 기존 솔루션이나 서비스보다 나은 점은 무엇인가요?
- **Q7.** 문서 처리 구조를 스크리닝 → 규칙 기반 즉답 → Specialist 호출의 계층형으로 나누셨습니다. 처음부터 모든 용어를 LLM으로 판정하는 방식 대신, 목표와 자동화 경계를 어떻게 정의하셨는지 설명해 주세요.
- **Q8.** 짧은 약어와 오탈자에 대응하기 위해 `difflib` + `text-embedding-3-large` + `pgvector (HNSW)` 기반 하이브리드 RAG를 선택하셨습니다. 순수 벡터 검색이나 규칙 기반 검색만 사용하지 않고 이 조합을 선택한 근거와, 정확도·운영 복잡도 간 트레이드오프는 무엇이었나요?
- **Q9.** Judge 피드백 기반 Self-Correction으로 미지 용어의 confidence를 0.5에서 0.96까지 높였다고 하셨습니다. 어떤 실패 유형을 가설로 설정하셨고, 재시도 횟수와 확정 기준(0.7)은 어떻게 정하셨나요? 단순 재호출보다 개선되었음을 어떤 방식으로 검증하셨나요?
- **Q10.** 결과물을 실무에 적용한다면, 업무 프로세스 개선을 위해 어떤 부분을 먼저 고도화하고 싶으신가요?
